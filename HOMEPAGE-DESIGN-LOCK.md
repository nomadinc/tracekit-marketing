## Change control

- **Do not make unsolicited visual or copy changes to the approved homepage.**
- Any deliberate design or copy modification requires explicit owner approval before implementation.
- Functional QA may identify necessary fixes; document the issue, scope the minimal correction, and verify desktop and mobile against this approved baseline.
- Secondary-page work should be isolated from homepage design files where practical.
- Do not merge into `development` or publish the Shopify theme solely because design approval is complete. Functional QA, page setup, and release approval remain separate gates.
- Avoid overlapping worktrees pushing to the same branch without synchronization.
- This document is an approval record, not a GitHub branch protection rule.
