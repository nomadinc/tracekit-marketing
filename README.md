# TraceKit Marketing

Public marketing website for TraceKit, built as a Shopify Online Store 2.0 theme.

## Product message

**North Star:** TraceKit connects every click, customer, and dollar into one verified truth—so businesses can understand what happened, why it happened, and what to do next.

**Homepage hook:** How much did you actually make yesterday?

## Development workflow

- `main` — reviewed/release-ready Shopify theme
- `development` — active marketing-site development
- feature branches — isolated work where needed

The TraceKit product application lives in a separate repository. This repository contains only the public marketing site.
